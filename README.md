# Bookly Pro V5

Production upgrade of the Bookly Pro booking SaaS.

## V5 includes
- Responsive owner application shell
- Modern dashboard with live Supabase metrics
- Appointment search and status filtering
- Customer directory generated from booking history
- Revenue and appointment reports
- Redesigned Services, Staff and Settings pages
- Notification center and mobile navigation

## Deploy
Upload the contents of this folder to the root of your existing GitHub Pages repository. Keep your existing Supabase project and run only SQL migrations you have reviewed. No database reset is required for this release.
